# CodeForgeAI

CodeForgeAI is an AI-powered coding assistant designed to make programming easier and more efficient.

## Features
- AI-powered code generation
- Code explanation
- Debugging assistance
- User-friendly interface

## Technologies Used
- Python / JavaScript
- React
- Vite
- AI integration

## Installation
1. Clone the repository.
2. Install dependencies.
3. Configure environment variables.
4. Run the development server.
